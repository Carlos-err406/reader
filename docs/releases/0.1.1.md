# Reader 0.1.1

- **About page.** Open it from the bottom of the library. It shows the version, can check for and install updates, and links to the source code, releases, issue tracker and MIT license, with credits for every open-source project Reader is built on.
- **Google sign-in button.** The sync panel now shows Google's logo on the sign-in button and next to your account.
- **Android sign-in** works in release builds.

## Install

**macOS**: Reader 0.1.0 updates itself. Accept the prompt in the library. For a new install, open `Reader-0.1.1-macos-universal.dmg` and drag Reader to Applications. The first time, right-click Reader and choose **Open**.

**Android**: Reader offers the new APK. Open it once it has downloaded. For a new install, download `Reader-0.1.1-android-arm64.apk` on the phone and open it.
