# Reader 0.1.2

- **Android updates install from the app.** Tap **Install** and Reader downloads the update, checks that it's the published file and signed by the same key, then opens Android's installer. The first time, Android asks you to allow Reader to install updates.
- **Nicer Google sign-in on desktop.** After you choose your account, the browser shows a proper confirmation page (or the real error) and offers to take you back to Reader.

## Install

**macOS**: Reader updates itself. Accept the prompt in the library. For a new install, open `Reader-0.1.2-macos-universal.dmg` and drag Reader to Applications. The first time, right-click Reader and choose **Open**.

**Android**: Reader 0.1.1 offers the new APK and opens it once it has downloaded. From this version on, updates download and install inside Reader. For a new install, download `Reader-0.1.2-android-arm64.apk` on the phone and open it.
