# Reader 0.1.3

- **Android updates install from the app, for real this time.** In 0.1.2, tapping **Install** failed with "registerListener not allowed by ACL" before the download began. Reader now downloads the update with a progress bar, checks it, and opens Android's installer.

## Install

**macOS**: Reader updates itself. Accept the prompt in the library. For a new install, open `Reader-0.1.3-macos-universal.dmg` and drag Reader to Applications. The first time, right-click Reader and choose **Open**.

**Android**: Reader 0.1.1 offers the new APK and opens it once it has downloaded. On 0.1.2, the in-app update fails, so download `Reader-0.1.3-android-arm64.apk` on the phone once and open it. From 0.1.3 on, updates install inside Reader. For a new install, download the same APK on the phone and open it.
