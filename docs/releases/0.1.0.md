# Reader 0.1.0

The first release: a PDF and EPUB reader for macOS and Android that keeps your place on both.

- Import PDFs and EPUBs; each book shows its own cover.
- Sync books, reading positions and bookmarks through your own Google Drive. Pull down in the library to sync right away.
- Continuous scrolling or page turns, full-screen reading, and tap to show the controls.
- Appearance (System, Light or Dark), four skins, bundled reading fonts, text size, line spacing and alignment.
- Pinch to zoom: PDFs magnify, EPUBs change text size live.
- When another device has read further, the reader offers to go there and highlights where you left off.

## Install

**macOS** (Apple Silicon and Intel, macOS 12+): open `Reader-0.1.0-macos-universal.dmg` and drag Reader to Applications. The first time, right-click Reader and choose **Open**, then **Open** again. Reader isn't notarized by Apple, so macOS asks once. Later versions update themselves.

**Android** (7.0+, 64-bit): download `Reader-0.1.0-android-arm64.apk` on the phone and open it. Allow your browser to install apps when Android asks. Reader offers new versions when they're released.
